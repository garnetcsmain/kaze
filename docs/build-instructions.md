# Build Instructions

## Binaries & Libraries

### Simple (SQLite3 FTS ext for Chinese search)

Download latest release from [GitHub Releases](https://github.com/wangfenjin/simple/releases), unzip into `[PROJECT_ROOT]/bin/[PLATFORM]/libsimple/`.

`[PLATFORM]`: `win32` (Windows) · `darwin` (macOS) · `linux` (Linux)
